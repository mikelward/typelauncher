# Curated package -> AppCategory overrides for apps that don't declare an
# appCategory in their manifest and don't register an Intent.CATEGORY_APP_*
# launcher intent. The inferrer applies this map as a third pass after the
# manifest signal and the APP_* probe.
#
# Format:
#   - One entry per line: "packageName=CategoryName"
#   - CategoryName must match an AppCategory enum constant (case-sensitive)
#   - Lines starting with # are comments. Blank lines are ignored.
#   - Whitespace around '=' is trimmed.
#
# When adding entries, prefer apps that:
#   - Are widely installed (top of their category in their region)
#   - Have a category Android lacks a built-in slot for (Finance, Banking, ...)
#   - Have a stable, well-known package name
#
# Apps that already declare appCategory or register an APP_* intent do NOT
# need to be listed here; the earlier passes catch them.
